# shop-kit

A tiny cart library: cart totals, discounts, tax and shipping, as plain ES modules.

- `src/` — the code, one module per concern.
- `test/` — `node --test`, one file per module.
- `docs/` — one page per concern.
- `CODING_STANDARDS.md` — the rules of the code.

Run the tests with `pnpm test`.
