`dw-sdlc gate` is quiet by default, in a terminal, for an agent and in CI. A green run prints one line per Step with its time, as `gate: step pnpm test — pass (71 s)`, one line per Check, as `gate: check primitives — pass`, and a last line, green or failed, and none of a Step's own output. A Step or `gate.checks.run` script runs with its two output streams captured into one, in the order written; when it does not pass, its last 50 lines print indented under its own line, as `gate: step pnpm test — failed, exit 1 (71 s); its last 50 lines:`, and its remedy reads `fix what it printed above; run it alone for the full output`. In a terminal a Step's line shows when it starts and takes its result in place when it ends; piped, each line prints once, finished. `--verbose` passes each command's output through live, colours kept, under a line naming it, and keeps no tail. `--json` keeps stdout to one document and, unless `--verbose` streams the commands to stderr, lets no command's output reach stderr; each Step and Check in it carries `tail`: the last 50 lines of a command that did not pass, null otherwise. SIGINT or SIGTERM sent while a command runs stops it and every command and Check after it, and the Gate still prints its report, the stopped command's last 50 lines and its failure line, `"<command>" was stopped by SIGINT`, included; a second signal, or one sent while the Checks the package ships run, ends the Gate at once. `dw-sdlc check <name>` captures a run script the same way and prints its last 50 lines when it fails. A command the shell cannot find or execute fails with its own remedy and exit 2.
