With no committed `.ai/agentic.config.json`, the local layer sets `pr.merge`, `pr.review` and `pr.ciUnavailable` freely. It is then the repository's only word on how a pull request ends, as in a repository the dev does not own under footprint local. A local `pr.review: light` there no longer drops the file and runs the strictest set. Beside a committed file the local layer still only tightens these keys, and its guardrails only tighten either way.
